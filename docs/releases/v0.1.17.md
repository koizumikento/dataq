# dataq v0.1.17 Release Notes

Released: 2026-03-04

## User-visible changes

- `codex install-skill` の既定配置先を更新しました。`--dest` 未指定時は `CODEX_HOME/skills` を優先し、`CODEX_HOME` 未設定時は `HOME/.agents/skills` を使います。
- README のサブコマンド一覧テーブルを Markdown プレビュー互換の高い記法へ修正しました。表セル内のオプション表記で `|` を直接使わない形に統一し、プレビュー崩れを解消しています。
- README / command spec の `codex install-skill` 配置先ドキュメントを実装と同期しました。

## Bug fixes and contract hardening

- `codex install-skill` のフォールバック解決を検証する統合テストを追加し、`HOME/.agents/skills` への配置契約を固定しました。

## Breaking changes

- None.
