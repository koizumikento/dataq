# dataq v0.1.16 Release Notes

Released: 2026-03-04

## User-visible changes

- Release workflow now prefers `docs/releases/<tag>.md` as the GitHub Release body and falls back to auto-generated notes when absent.
- Homebrew tap publish workflow now triggers on `release.published` and still supports manual `workflow_dispatch`.
- Homebrew formula generation now includes command integration dependencies: `csvkit`, `jc`, `qsv`, `duckdb`, and `check-jsonschema`.
- README / command spec documentation was synchronized with implemented commands: `ingest jc`, `ingest notes`, `ingest book`, and `schema infer`.
- Bundled dataq agent skill routing/prompt was updated to match the current command set and deterministic diagnostics flow.

## Bug fixes and contract hardening

- Fixed `transform` command help text to correctly describe `jq -> mlr` stage order.
- Synced `Cargo.lock` with package version for locked release builds.

## Breaking changes

- None.
