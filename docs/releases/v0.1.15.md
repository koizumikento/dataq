# dataq v0.1.15 Release Notes

Released: 2026-03-04

## User-visible changes

- Release workflow now prefers `docs/releases/<tag>.md` as the GitHub Release body and falls back to auto-generated notes when the file is absent.
- Homebrew tap publish workflow now triggers on `release.published` and still supports manual `workflow_dispatch`.
- Homebrew formula generation now includes integration dependencies used by implemented commands: `csvkit`, `jc`, `qsv`, `duckdb`, and `check-jsonschema`.
- README / command spec now document `ingest jc`, `ingest notes`, `ingest book`, and `schema infer` usage and dependency requirements in line with the current implementation.
- Bundled dataq agent skill routing/prompt was updated to match current command set and deterministic diagnostics flow.

## Bug fixes and contract hardening

- CLI top-level help text for `transform` was corrected from `jq -> sql` to `jq -> mlr`.
- Homebrew/release docs were synchronized with current CI trigger and release note resolution behavior.

## Breaking changes

- None.
